System Topology Layers

1. Frontend Client Layer

React 19 + Vite

Runs on http://localhost:5173. Manages the visual SPA using React Router v7, Zustand (persistent auth), and Axios with automatic JWT injection.

2. Gateway & Middleware Layer

FastAPI + Starlette

Runs on http://localhost:8000. Manages CORS, SlowAPI rate limiting (5 req/min on login), global error formatting, and app lifespan events.

3. Routers & Security Layer

OAuth2 + JWT

Distributes endpoints across Universal (/api/v1/auth), Admin (/api/v1/admin/* with require_admin), Member Portal (/api/v1/user/* with get_current_user), and Shared.

4. Data & Persistence Layer

SQLAlchemy Async + SQLite / PostgreSQL

Relational models with UUID primary keys (preventing enumeration attacks). Uses selectinload for eager loading relationships without N+1 query overhead.

5. Background Scheduler & External Services

APScheduler + Resend API

AsyncIOScheduler runs inside the Python event loop without blocking HTTP requests. Evaluates expiring memberships and sends transactional emails with idempotency logging.

Key File Connections

backend/main.py

The central entry point. Configures CORS, initializes SlowAPI rate limiter, starts APScheduler in the lifespan context manager, and registers all API routers.

backend/app/limiter.py

Creates the singleton Limiter(key_func=get_remote_address). Extracts client IP from incoming requests to prevent credential-stuffing attacks.

backend/app/scheduler.py & app/jobs/expiry_checker.py

Manages daily background tasks. Evaluates memberships at 7, 3, 1, and 0 days, checks notification_logs to avoid sending duplicate emails, and calls Resend.

frontend/src/api/client.js

Axios singleton. Attaches Authorization: Bearer <token> automatically to every outgoing request and handles 401 errors with redirect to /login.

frontend/src/store/authStore.js

Zustand state store with persist middleware. Stores user role, username, and token, keeping the user logged in across page reloads.
